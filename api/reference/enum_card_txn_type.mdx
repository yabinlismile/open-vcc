## 卡交易类型

| 编码 | 描述 |
|------|---------|
| `1` | 消费 |
| `2` | 充值 |
| `3` | 取款 |
| `4` | 转账(转入) |
| `5` | 转账(转出) |
| `6` | 其他 |
| `7` | 结算调整 |
| `8` | 退款 |
| `9` | 消费失败 |
| `10` | 绑卡验证交易（verification） |
| `11` | 撤销（void，付款后撤销，退回资金） |
| `12` | 授权 |
| `13` | 卡管理费 |
| `14` | 交易拒绝 |
