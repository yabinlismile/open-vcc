## 充值状态

| 编码 | 描述 |
|------|---------|
| `0` | 待处理中 |
| `1` | 充值成功 |
| `2` | 充值失败 |
| `3` | 充值已提交 |
| `4` | 存疑 |
| `5` | 后台取消 |
| `6` | 待审核 |
| `7` | 已退款 |
