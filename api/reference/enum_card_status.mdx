## 卡状态

| 编码 | 描述 |
|------|---------|
| `0` | 冻结 |
| `1` | 激活成功 |
| `2` | 未激活 |
| `3` | 激活待审核 |
| `4` | 激活审核失败 |
| `5` | 申请失败(卡片正在制作中，请过会再申请) |
| `6` | 开卡申请成功（实体卡制作中） |
| `8` | 销卡中 |
| `9` | 已销卡 |
