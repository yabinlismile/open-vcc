---

```
GET https://{baseUrl}/api/v1/institution/balance
```

## 请求参数
无

## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| coin\_type | String | 数字货币类型 |
| addresses\[0\].balance | String | 数字货币余额 |
| addresses\[0\].address\_type | String | 数字货币地址类型，开卡（open\_card）和充值（deposit） |
| addresses\[0\].address | String | 数字货币地址 |


## 交易报文

无
