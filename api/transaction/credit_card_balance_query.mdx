---
title: "Query Credit Card Balance"
sidebarTitle: "Credit Balance"
description: "GET /api/v1/credit/user/detail — retrieve a credit card's credit limit, available balance, and pre-authorized amount."
---

```
GET https://{baseUrl}/api/v1/credit/user/detail
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| acct\_no | String | 必填 | 机构用户的唯一id号 |
| card\_no | String | 必填 | 银行卡ID |


## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| amount\_limit | String | 授信额度 |
| available\_amount | String | 可用金额 |
| pre\_authorize\_amount | String | 预授权金额 |
