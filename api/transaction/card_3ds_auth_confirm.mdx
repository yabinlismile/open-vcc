```
POST https://{baseUrl}/api/v1/bank/3dsConfirm
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card\_no | String | 必填 | 银行卡ID |
| txn\_id | String | 必填 | 流水号，对应3ds授权通知的流水号 |
| status | String | 必填 | 0确认，1取消 |
