```
POST https://{baseUrl}/api/v1/bank/3dsConfirm
```

## 请求参数

| Parameter | Type | Requirement | Description |
| :--- | :--- | :--- | :--- |
| card_no | String | M | 银行卡ID |
| txn_id | String | M | 流水号，对应3ds授权通知的流水号 |
| status | String | M | 0确认，1取消 |
