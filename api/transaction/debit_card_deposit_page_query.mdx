---

```
GET https://{baseUrl}/api/v1/deposit-transactions
```

## 请求参数

| Parameter | Type | Requirement | Description |
| :--- | :--- | :--- | :--- |
| acct_no | String | O | 机构端用户编号(机构端唯一) |
| page_num | int | O | 页数，默认第1页 |
| page_size | int | O | 页的大小，默认20条 |
| former_time | long | O | 前置时间：UNIX 时间戳，`秒为单位` |
| latter_time | long | O | 后置时间：UNIX 时间戳，`秒为单位` |
| time_sort | String | O | 时间排序：asc为正序，desc为反序，默认desc |


## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| cust_tx_id | String | 机构流水号 |
| acct_no | String | 机构端用户编号(机构端唯一) |
| card_no | int | 银行卡ID |
| cust_tx_time | long | 创建时间 |
| tx_id | String | 交易id |
| coin_type | int | 充值币种 |
| tx_amount | String | 充值金额 |
| exchange_fee | String | 充值币种兑换成USDT的费用，单位是 `coin_type` |
| loading_fee | String | 充值手续费，单位是 `coin_type` |
| currency_type | String | 到账法币类型 |
| currency_amount | String | 到账法币数量 |
| exchange_rate | String | USDT/法币汇率 |
| fiat_exchange_rate | String | 卡支持的法币/USD汇率 |
| tx_status | int | 交易状态：详见 [充值状态](/api/reference/enum_trans_status#充值状态) |
| coin_price | String | coin_type/USD汇率 |
