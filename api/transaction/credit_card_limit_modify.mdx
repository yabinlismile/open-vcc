---
title: "Modify Credit Card Spending Limit"
sidebarTitle: "Modify Limit"
description: "POST /api/v1/bank/cardlimit — set per-transaction, daily, and monthly spending limits on a credit card. All limit fields are optional."
---

```
POST https://{baseUrl}/api/v1/bank/cardlimit
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card\_no | String | 必填 | 银行卡ID |
| max\_amount\_single | String | 可选 | 当笔限额 |
| max\_amount\_daily | String | 可选 | 日限额 |
| max\_amount\_monthly | String | 可选 | 月限额 |


## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| card\_no | String | 银行卡ID |
| card\_type | String | 银行卡类型 |
| max\_amount\_single | String | 当笔限额 |
| max\_amount\_daily | String | 日限额 |
| max\_amount\_monthly | String | 月限额 |
| available\_balance | String | 可用余额 |
