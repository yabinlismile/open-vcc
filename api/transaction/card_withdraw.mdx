```
POST https://{baseUrl}/api/v1/deposit-transactions/withdraw
```

## 请求参数

| Parameter | Type | Requirement | Description |
| :--- | :--- | :--- | :--- |
| card_no | String | M | 银行卡ID |
| acct_no | String | M | 机构端用户编号(机构端唯一) |
| amount | String | M | 提现对应币种的金额 最多可以有10位数字 小数部分最多可以有2位数字|
| coin_type | String | M | 币种。只支持USDT |
| cust_tx_id | String | M | 机构的交易流水号 |
| remark | String | O | 交易备注 |


## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| tx_id | String | remCard 交易流水id |
| withdraw_amounte | String | 提现金额 |
| balance | String | 提现后备付金余额 |
| before_balance | String | 提现前备付金余额 |
