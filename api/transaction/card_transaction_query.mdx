---

```
POST https://{baseUrl}/api/v1/bank/transactionQuery
```

## 请求参数

| Parameter | Type | Requirement | Description |
| :--- | :--- | :--- | :--- |
| page_num | int | O | 页数，默认1 |
| page_size | int | O | 页的大小，默认20 |
| card_no | String | O | 银行卡ID |
| txn_type | String | O | 交易类型，详见[卡交易类型](/api/reference/enum_card_txn_type#卡交易类型) |
| trace_no | String | O | 订单跟踪号（与交易流水号不同时为空）  |
| txn_id | String | O | 交易流水号 |
| txn_start_time | strng | O | 查询交易开始时间：yyyy-MM-dd HH:mi:ss |
| txn_end_time | strng | O | 查询交易结束时间：yyyy-MM-dd HH:mi:ss |


## 响应参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| trace_no | String | 订单跟踪号 |
| tx_type | String | 交易类型，详见[卡交易类型](/api/reference/enum_card_txn_type#卡交易类型) |
| tx_status | String | 交易状态，详见[交易状态](/api/reference/enum_trans_status#交易状态) |
| tx_id | String | 交易ID |
| orig_tx_id | String | 原交易ID |
| card_no | String | 银行卡ID |
| transaction_date | String | 交易日期 |
| transaction_time | Date | 交易时间戳 |
| tx_amount | String | 实际交易金额 |
| tx_currency | String | 实际交易货币 |
| bill_amount | String | 账单金额 |
| bill_currency | String | 账单币种 |
| fee | String | 手续费，只有部分卡有，fee包含fx_fee |
| fx_fee | String | 换汇手续费，涉及换汇会有 |
| description | String | 交易描述 |
| reason | String | 交易失败原因 |
| merchant_country | String | 商户国家 |
| merchant_name | String | 商户名称 |
| merchant_mcc | String | 商户mcc码 |
