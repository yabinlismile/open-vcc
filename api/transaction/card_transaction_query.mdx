---
title: "Query Card Transactions"
sidebarTitle: "Transaction Query"
description: "POST /api/v1/bank/transactionQuery — search card transactions by card number, type, date range, trace number, or transaction ID. Supports pagination."
---

```
POST https://{baseUrl}/api/v1/bank/transactionQuery
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| page\_num | int | 选填 | 页数，默认1 |
| page\_size | int | 选填 | 页的大小，默认20 |
| card\_no | String | 选填 | 银行卡ID |
| txn\_type | String | 选填 | 交易类型，详见[卡交易类型](/api/reference/enum_card_txn_type#卡交易类型) |
| trace\_no | String | 选填 | 订单跟踪号（与交易流水号不同时为空）  |
| txn\_id | String | 选填 | 交易流水号 |
| txn\_start\_time | strng | 选填 | 查询交易开始时间：yyyy-MM-dd HH:mi:ss |
| txn\_end\_time | strng | 选填 | 查询交易结束时间：yyyy-MM-dd HH:mi:ss |


## 响应参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| trace_no | String | 订单跟踪号 |
| card_no | String | 卡ID |
| credit | String | 存入金额(卡支持的货币) |
| credit_usd | String | 存入金额(USD) |
| credit_usdt | String | 存入金额(USDT) |
| debit | String | 消费金额(卡支持的货币) |
| debit_usd | String | 消费金额(USD) |
| debit_usdt | String | 消费金额(USDT) |
| description | String | 描述 |
| fee | String | 手续费，只有部分卡有，fee=fxFee+authFee+atmFee+fixedFee |
| fxFee | String | 换汇手续费，涉及换汇会有 |
| authFee | String | 授权手续费，只有部分卡有 |
| atmFee | String | ATM手续费，只有部分卡有 |
| fixedFee | String | 固定手续费，只有部分卡有 |
| origin_transaction_id | String | 原交易流水号（当追加授权时，返回的是首次授权订单跟踪号） |
| posting_date | String | 交易提交日期 |
| reason | String | 交易失败原因 |
| transaction_date | String | 交易日期 |
| transaction_time | Date | 交易时间戳 |
| tx_amount | String | 实际交易货币的交易金额 |
| tx_currency | String | 实际交易货币 |
| end_bal | String | 交易后余额。如果是0 代表没交易后余额 |
| tx_id | String | 交易流水号 |
| type | int |交易类型 |
| merchant_country | String | 商户国家 |
| merchant_name | String | 商户名称 |
| merchant_mcc | String | 商户mcc码 |
