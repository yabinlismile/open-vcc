```
GET https://{baseUrl}/api/v1/credit/getCardLimitTxn
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card\_no | String | M | 银行卡ID |
| cust\_tx\_id | String | O | 机构交易流水id |
| tx\_id | String | O | 平台交易流水id |
| page\_num | int | O | 页数，默认第1页 |
| page\_size | int | O | 页的大小，默认20条 |
| former\_time | long | O | 前置时间：UNIX 时间戳，`秒为单位` |
| latter\_time | long | O | 后置时间：UNIX 时间戳，`秒为单位` |
| time\_sort | String | O | 时间排序：asc为正序，desc为反序，默认desc |


## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| tx\_id | String | remCard 交易流水id |
| cust\_tx\_id | String | 机构交易流水id |
| card\_no | String | 银行卡ID |
| amount_limit | String | 当前限额 |
| old_amount_limit | String | 旧限额 |
| status | String | 交易状态。 "0" 处理中，"1" 是成功，"2" 是失败 |
| amount_modify | String | 变化的金额 |
| available\_amount | String | 可用金额 |
| old\_available\_amount | String | 旧的可用金额 |
