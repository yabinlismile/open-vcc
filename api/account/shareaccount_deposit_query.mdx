## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| tx_id | String | O | 交易流水号，与cust_tx_id必传其一 |
| cust_tx_id | String | O | 机构请求流水号，与tx_id必传其一 |


## 响应参数

| Parameter | Type | Requirement| Description |
| --- | --- | --- | --- |
| status | number | M | 0处理中，1成功，2失败 |
| amount | number | M | 金额，单位是usdt |
