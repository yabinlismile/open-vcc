description: "PUT /api/v1/customers/accounts/updateEmailMobile — change the email address and mobile number linked to a user's card."
---

```
PUT https://{baseUrl}/api/v1/customers/accounts/updateEmailMobile
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card\_no | String | 必填 | 卡号 |
| mail | String | 选填 | 邮箱，与手机号不能都为空 |
| country\_code | String | 选填 | 手机号区号（手机号非空时，必填） |
| mobile | String | 选填 | 手机号，与手机号不能都为空 |
