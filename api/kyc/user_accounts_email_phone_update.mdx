```
PUT https://{baseUrl}/api/v1/customers/accounts/updateEmailMobile
```

## 请求参数

| Parameter | Type | Requirement | Description |
| :--- | :--- | :--- | :--- |
| card_no | String | M | 卡号 |
| mail | String | O | 邮箱，与手机号不能都为空 |
| country_code | String | O | 手机号区号（手机号非空时，必填） |
| mobile | String | O | 手机号，与手机号不能都为空 |
