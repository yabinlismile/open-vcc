```
PUT https://{baseUrl}/api/v1/customers/accounts
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| acct\_no | String | 必填 | 机构用户的唯一id号 |
| kyc\_info | String | 必填 | kyc\_info |
