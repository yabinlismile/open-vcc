---
title: "活体认证"
sidebarTitle: "活体认证"
description: "获取用户活体认证链接"
---

```
GET https://{baseUrl}/api/v1/customers/accounts/url
```

## 请求参数

| Parameter | Type | Requirement | Description |
| :--- | :--- | :--- | :--- |
| acct_no | String | M | 机构用户的唯一id号 |
| card_type_id | String | O | 卡种类型ID（与bank_id二选一） |
| bank_id | String | O | 银行ID（与card_type_id二选一） |


## 响应参数


| Parameter | Type   | Description  |
|-----------|--------|---------------|
| face_recognition_url      | String    | 活体认证链接：https://xxx  |
| expiration_time       | String |  过期时间（分钟） |
