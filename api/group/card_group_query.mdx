```
GET https://{baseUrl}/api/v2/cardGroup/query
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card_group_id | String | M | 卡组ID |


## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| card_group_id | String | 卡组ID |
| card_group_name | String | 卡组名称 |
| total_amount | String | 总余额 |
| available_amount | String | 可用余额 |
