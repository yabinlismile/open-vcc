```
POST https://{baseUrl}/api/v2/cardGroup/deposit
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card_type_id | String | M | 卡种id，如20000001 |
| card_group_id | String | M | 卡组ID|
| amount | String | M | 交易金额，单位是usdt |
| cust_tx_id | String | O | 机构唯一的流水号 |


## 响应参数

| Parameter | Type | Requirement| Description |
| --- | --- | --- | --- |
| tx_id | String | M | bycard返回唯一的流水号 |
| old_balance | number | O | 变成前余额，仅成功时返回 |
| balance | number | O | 变成后余额，仅成功时返回 |
| cust_tx_id | String | O | 机构唯一的流水号 |
| status | number | M | 0处理中，1成功，2失败 |
