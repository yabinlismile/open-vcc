---
title: "卡种账户余额查询"
sidebarTitle: "卡种账户余额查询"
description: "卡种对应的账户余额查询"
---

```
GET https://{baseUrl}/api/v2/virtualAccount/balanceQuery
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card_type_id | String | M | 卡种id |


## 响应参数

| Parameter | Type   | Description  |
|-----------|--------|---------------|
| balance   | String | 账户余额 |

## 交易报文

<CodeGroup>
```json Request
card_type_id=20000001
```

```json Response
{
  "code": 0,
  "msg": "string",
  "result": {
    "balance": "20"
  }
}
```
</CodeGroup>
