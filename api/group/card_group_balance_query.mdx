```
GET https://{baseUrl}/api/v2/cardGroup/balanceQuery
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card_type_id | String | M | 卡种id |
| card_group_id | String | M | 卡组ID|


## 响应参数

| Parameter | Type   | Description  |
|-----------|--------|---------------|
| balance   | String | 余额 |
