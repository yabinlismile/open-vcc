---
title: "Freeze a Card"
sidebarTitle: "Freeze"
description: "POST /api/v1/bank/freeze — temporarily suspend a card to block all new transactions. The card can be unfrozen later."
---

```text
POST https://{baseUrl}/api/v1/bank/freeze
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card\_no | String | 必填 | 银行卡ID |
