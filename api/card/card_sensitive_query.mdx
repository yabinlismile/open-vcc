title: "Query Sensitive Card Details"
sidebarTitle: "Sensitive Details"
description: "POST /api/v1/bank/virtualcard or /api/v1/bank/card — retrieve encrypted sensitive card data (card number, CVV, expiration) using your uploaded public key."
---

```text
虚拟卡：POST https://{baseUrl}/api/v1/bank/virtualcard

实体卡：POST https://{baseUrl}/api/v1/bank/card
```

## 请求参数

| Parameter | Type | Whether Required | Description |
| --- | --- | --- | --- |
| card\_no | String | Required | card no |
| publickey | String | Optional | 我们会使用这个公钥替代 默认的公钥（需要自己调用接口上传）加密数据，支持ECIES和RSA |

## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| encrypt\_data | String\[\] | 敏感密文信息：敏感信息加密后的数据 |
| public\_key | String | 公钥 |
