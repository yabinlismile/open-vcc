```
POST https://{baseUrl}/api/v1/debit-cards
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| acct\_no | String | 必填 | 机构端用户编号(机构端唯一) |
| card\_type\_id | String | 必填 | 卡种对应的id |
| card\_number | String | 选填 | 支持绑卡的卡种才需要填写。用户自己填写卡号绑卡 |
| urn | String | 选填 | 支持绑卡的卡种才需要填写。信封号 |
| address | String | 选填 | 账单地址或者实体卡邮寄地址。字符长度最大256 |
| country | String | 选填 | 国家，字符长度最大50，2位编码 |
| state | String | 选填 | 省份，字符长度最大100 |
| city | String | 选填 | 城市，字符长度最大100 |
| zipcode | String | 选填 | 邮编，字符长度最大20 |
| country_code | String | 选填 | 手机国际区号，如“+86”。字符长度最大5 |
| mobile | String | 选填 | 手机号，字符长度最大32 |
| cust_tx_id | String | 选填 | 机构的开卡流水号，最大64 |


## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| card\_no | String | 分配的银行卡ID，查询时用card\_no，避免真是卡号信息泄露。生成规则：机构id+8位随机数 +卡种id +卡最后四位 |
| card\_number | String | 分配的真实银行卡号, 只显示前6位和后4位 |
| status | int | 状态码，详见 [卡片状态](/api/reference/enum_card_status#卡状态) |
