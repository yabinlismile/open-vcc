```
POST https://{baseUrl}/api/v1/card/apply
```


## 请求参数

| Parameter | Type | Requirement | Length | Description |
| :--- | :--- | :--- | :--- | :--- |
| acct_no | String | M | 64 | 机构端用户编号唯一 |
| card_type_id | String | M | 10 | 卡种对应的id |
| card_number | String | O | 32 | 特殊卡种可绑卡 |
| active_code | String | O | 32 | 激活码 |
| urn | String | O | 50 | 信封号 |
| address | String | O |  256| 账单地址/邮寄地址 |
| country | String | O | 50 | 国家，2位编码 |
| state | String | O | 100 | 省份 |
| city | String | O | 100 | 城市 |
| zipcode | String | O | 20 | 邮编 |
| country_code | String | O | 5 | 手机国际区号，如“+86” |
| mobile | String | O | 32 | 手机号 |
| cust_tx_id | String | O | 64 | 机构的开卡流水号 |


## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| card_no | String | 分配的银行卡ID，查询时用card_no，避免真是卡号信息泄露。生成规则：机构id+8位随机数 +卡种id +卡最后四位 |
| card_number | String | 分配的真实银行卡号, 只显示前6位和后4位 |
| status | int | 状态码，详见 [卡片状态](/api/reference/enum_card_status#卡状态) |
