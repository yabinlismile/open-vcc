---
title: "Activate a Card"
sidebarTitle: "Activate"
description: "POST /api/v1/debit-cards/status — activate a virtual or physical card. After activation, query card details to retrieve the real card number, CVV, and expiration date."
---

```text
POST https://{baseUrl}/api/v1/debit-cards/status
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card\_no | String | 必填 | 银行卡ID |
| acct\_no | String | 必填 | 机构端用户编号(机构端唯一) |
| cvv | String | 选填 | 特定实体卡激活需要cvv |

## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| acct\_no | String | 机构端用户编号(机构端唯一) |
| card\_type\_id | String | 卡类型ID |
| card\_no | int | 卡ID |
| status | int | 状态码，详见 [卡片状态](/api/reference/enum_card_status#卡状态) |
