---
title: "卡账单查询"
sidebarTitle: "卡账单查询"
description: "查询卡交易账单记录"
---

```
POST https://{baseUrl}/api/v1/bank/transaction-record
```

## 请求参数

| Parameter | Type | Requirement | Description |
| :--- | :--- | :--- | :--- |
| card_no | String | M | 卡号 |
| card_currency | String | O | 卡币种，双币种卡才需要填写 |
| former_month_year | String | M | 指定查询的月份(格式“012020”) |
| latter_month_year | String | M | 指定查询的月份(格式“012020”) |
| tx_id | String | O | 交易id，tx_id非空时月份可不填 |


## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| month_year | String | 日期，MMyyyy |
| statement_cycle_date | String | 报表生成日期 |
| opening_balance | String | 起始余额(卡支持的货币) |
| opening_balance_usd | String | 起始余额(USD) |
| closing_balance | String | 截止余额(卡支持的货币) |
| closing_balance_usd | String | 截止余额(USD) |
| available_balance | String | 可用余额(卡支持的货币) |
| available_balance_usd | String | 可用余额(USD) |
| bank_tx_list[n] | Object | 交易列表 |
| bank_tx_list[0].trace_no | String | 订单跟踪号 |
| bank_tx_list[0].tx_type | String | 交易类型，详见[卡交易类型](/api/reference/enum_card_txn_type#卡交易类型) |
| bank_tx_list[0].tx_status | String | 交易状态，详见[交易状态](/api/reference/enum_trans_status#交易状态) |
| bank_tx_list[0].tx_id | String | 交易ID |
| bank_tx_list[0].orig_tx_id | String | 原交易ID |
| bank_tx_list[0].card_no | String | 卡号 |
| bank_tx_list[0].transaction_date | String | 交易日期 |
| bank_tx_list[0].transaction_time | Date | 交易时间戳 |
| bank_tx_list[0].tx_amount | String | 实际交易金额 |
| bank_tx_list[0].tx_currency | String | 实际交易货币 |
| bank_tx_list[0].bill_amount | String | 账单金额 |
| bank_tx_list[0].bill_currency | String | 账单币种 |
| bank_tx_list[0].fee | String | 手续费，只有部分卡有，fee包含fx_fee |
| bank_tx_list[0].fx_fee | String | 换汇手续费，涉及换汇会有 |
| bank_tx_list[0].description | String | 交易描述 |
| bank_tx_list[0].reason | String | 交易失败原因 |
| bank_tx_list[0].merchant_country | String | 商户国家 |
| bank_tx_list[0].merchant_name | String | 商户名称 |
| bank_tx_list[0].merchant_mcc | String | 商户mcc码 |
