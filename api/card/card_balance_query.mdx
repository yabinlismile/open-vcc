---
title: "Query Card Balance"
sidebarTitle: "Balance"
description: "POST /api/v1/bank/balance — retrieve the current and available balance for a card in both the card currency and USD."
---

```text
POST https://{baseUrl}/api/v1/bank/balance
```

## 请求参数

| Parameter | Type | Requirement | Description |
| --- | --- | --- | --- |
| card\_no | String | 必填 | 银行卡ID |
| card\_currency | String | 选填 | 卡币种，双币种卡才需要填写 |

## 响应参数

| Parameter | Type | Description |
| --- | --- | --- |
| card\_number | String | 真实银行卡号 |
| card\_type | String | 银行卡类型 |
| current\_balance | String | 当前余额（卡支持的货币） |
| current\_balance\_usd | String | 当前余额（USD） |
| available\_balance | String | 可用余额（卡支持的货币） |
| available\_balance\_usd | String | 可用余额（USD） |
