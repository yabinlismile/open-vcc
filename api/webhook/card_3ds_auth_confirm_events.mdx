## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-3ds-auth |
| txn_id | String | 订单号 |
| card_no | String | 卡id |
| transaction_currency | String | 交易货币 |
| transaction_amount | String | 交易金额 |
| merchant_name | String | 商户名 |
