## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | auth-fee-charged |
| events\[n\].params.card\_no | String | 银行卡ID |
| events\[n\].params.order\_id | String | 业务单号 |
| events\[n\].params.tx\_id | String | 关联交易单号 |
| events\[n\].params.coin\_type | String | 扣费币种 |
| events\[n\].params.tx\_amount | BigDecimal | 扣费金额 |
| events\[n\].params.remark | String | 备注 |
