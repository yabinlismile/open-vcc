## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | auth-fee-charged |
| card\_no | String | 银行卡ID |
| order\_id | String | 业务单号 |
| tx\_id | String | 关联交易单号 |
| coin\_type | String | 扣费币种 |
| tx\_amount | BigDecimal | 扣费金额 |
| remark | String | 备注 |
