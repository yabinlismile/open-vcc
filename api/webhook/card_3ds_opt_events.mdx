## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-3ds-otp |
| events\[n\].params.otp | String | 验证码 |
| events\[n\].params.card\_no | String | 卡id |
| events\[n\].params.transaction\_currency | String | 交易货币 |
| events\[n\].params.transaction\_amount | String | 交易金额 |
| events\[n\].params.merchant\_name | String | 商户名 |
