## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-3ds-otp |
| otp | String | 验证码 |
| card\_no | String | 卡id |
| transaction\_currency | String | 交易货币 |
| transaction\_amount | String | 交易金额 |
| merchant\_name | String | 商户名 |
