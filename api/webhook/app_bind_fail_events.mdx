## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-app-pay-otp-fail |
| card_no | String | 卡id |
| reason | String | 失败原因 |
| opt_type | String | 应用类型，APPLE_PAY、GOOGLE_PAY，为空则默认APPLE_PAY |
