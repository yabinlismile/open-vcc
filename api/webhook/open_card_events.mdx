## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-application-ready |
| events\[n\].params.acct\_no | String | 机构下用户唯一ID |
| events\[n\].params.card\_type\_id | String | 卡类型 |
| events\[n\].params.card\_no | String | 卡ID |
| events\[n\].params.status | int | 开卡状态：2. 待激活, 4. 开卡失败 |
| events\[n\].params.reason | String | 开卡失败原因 （如果status为 2 则为空） |
| events\[n\].params.cust_tx_id | String | 机构的开卡流水号 |
