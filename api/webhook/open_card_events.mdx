## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-application-ready |
| acct_no | String | 机构下用户唯一ID |
| card_type_id | String | 卡类型 |
| card_no | String | 卡ID |
| status | int | 开卡状态：2. 待激活, 4. 开卡失败 |
| reason | String | 开卡失败原因 （如果status为 2 则为空） |
| cust_tx_id | String | 机构的开卡流水号 |
