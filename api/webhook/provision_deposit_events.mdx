## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | back-fund-recharge |
| order_no | String | 订单号 |
| tx_time | String | 交易时间，格式：yyyy-MM-dd HH:mm:ss |
| amount | String | 备付金充值入账金额 |
| reason | String | 备注 |
