## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | tx-status |
| tx_id | String | 交易ID |
| status | int | 卡充值状态：1.成功, 2.失败, 5.取消 |
| reason | String | 原因（如果status为 1，5 则为空） |
