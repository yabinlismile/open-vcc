<Note>
1. 接收到卡交易待确认请求信息后，实时返回接受通知是否消费结果。
2. 接口性能：确保回调接口响应时间 < 1 秒（预留网络传输时间），超过 1.5 秒将被视为超时拒绝
</Note>


## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
|action|string|事件类型：credit-transaction-confirm|
|trace_no|String|订单跟踪号（与信用卡消费事件一致）|
|card_no|String|卡号|
|additional_auth|String|是否是追加授权：0是，1否|
|acct_no|String|用户编号|
|txn_time|String|交易时间，格式：yyyy-MM-dd HH:mm:ss|
|bill_amount|String|交易金额|
|bill_currency|String|交易币种：USD|
|txn_amount|String|本地金额|
|txn_currency|String|交易币种：交易时用的币种|
|atm_txn_flag|String|是否AMT交易：0是，1否|
|merchant_data|String|商户数据|
|- mcc_code |String|商户类别代码|
|- merchant_id|String|商户号|
|- merchant_country|String|商户所在国家|
|- merchant_name|String|商户名称|


## 响应参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| status | String | 是否消费：0确认消费，1拒绝消费，必填 |
| reason | String | 原因：拒绝消费时，建议填写 |
