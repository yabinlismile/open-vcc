## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-status |
| events\[n\].params.acct\_no | String | 机构下用户唯一ID |
| events\[n\].params.card\_no | String | 卡ID |
| events\[n\].params.status | int | 卡激活状态：0.冻结, 1.卡激活成功, 4.卡激活审核失败, 9.已销卡|
| events\[n\].params.reason | String | 原因（如果status为 0，1 则为空） |
| events\[n\].params.cust_tx_id | String | 机构的开卡流水号 |
