## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-status-active |
| acct_no | String | 机构下用户唯一ID |
| card_no | String | 卡ID |
| status | int | 卡激活状态：0.冻结, 1.卡激活成功, 4.卡激活审核失败, 9.已销卡|
| reason | String | 原因（如果status为 0，1 则为空） |
| cust_tx_id | String | 机构的开卡流水号 |
