## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | kyc-status |
| acct\_no | String | 机构下用户唯一ID |
| bank_id | String | 银行类型 |
| card\_type\_id | String | 卡类型 |
| status | int | KYC状态：1. 成功, 2. 失败 |
| reason | String | KYC失败原因 （如果status为 1 则为空）|
