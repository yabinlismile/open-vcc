## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | kyc-status |
| events\[n\].params.acct\_no | String | 机构下用户唯一ID |
| events\[n\].params.bank_id | String | 银行类型 |
| events\[n\].params.card\_type\_id | String | 卡类型 |
| events\[n\].params.status | int | KYC状态, 1. 成功, 2. 失败 |
| events\[n\].params.reason | String | KYC失败原因 （如果status为 1 则为空）|
