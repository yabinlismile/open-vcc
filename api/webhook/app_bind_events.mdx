## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-app-pay-otp |
| events\[n\].params.otp | String | 验证码 |
| events\[n\].params.card\_no | String | 卡id |
| events\[n\].params.opt\_type | String | 应用类型，APPLE_PAY、GOOGLE_PAY，为空则默认APPLE_PAY |
