## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-app-pay-otp |
| otp | String | 验证码 |
| card\_no | String | 卡id |
| opt\_type | String | 应用类型，APPLE_PAY、GOOGLE_PAY，为空则默认APPLE_PAY |
