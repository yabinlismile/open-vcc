---

## 请求参数

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| action | String | card-lock-status |
| events\[n\].params.card\_no | String | 卡ID |
| events\[n\].params.status | int | 0.处理中 1.成功 2.失败 |
| events\[n\].request\_type | int | 1.冻结 2.解冻 3.挂失 4.重置密码 5.补卡 9.销卡完成|
| events\[n\].params.amount | String | 10.00 （type为 9才会有值  正数 此金额会直接退回充值备付金中  如果为负数 此金额会直接扣减充值备付金） |
