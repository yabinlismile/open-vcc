ByCard returns structured error codes in every API response. A `code` value of `0` means success. Any non-zero code indicates an error. This page lists all error codes grouped by category and explains what to do when you encounter them.

## Common response format

Every API response uses the same envelope structure:

```json
{
  "code": 0,
  "msg": "SUCCESS",
  "result": { }
}
```

When an error occurs, `code` is non-zero and `msg` contains a description of the problem.

## Troubleshooting tips

| Symptom | Likely cause | Resolution |
| --- | --- | --- |
| `112003` Illegal IP | Your server IP changed or is not whitelisted. | Update the IP whitelist in the dashboard. |
| `112005` or `112007` Signature errors | Timestamp drift, sorting error, or wrong secret. | Verify your clock is accurate, sort body keys in ASCII order, and check your API Secret. |
| `111011` Insufficient balance | Institution wallet balance too low for the requested deposit or fee. | Fund your wallet via the dashboard. |
| `111002` KYC status abnormal | User KYC is pending, failed, or missing. | Check KYC status and resubmit if needed. |
| `111013` Card status abnormal | Card is frozen, cancelled, or not yet activated. | Query card status and take the appropriate action. |
